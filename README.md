# 🎯 Rock Paper Scissors AI Pattern Prediction Challenge

## 📝 Problem Description
You are tasked with building an intelligent Rock Paper Scissors (RPS) engine that learns player behavior and predicts their next move.  
The goal is to simulate a competitive AI opponent that **adapts** over time.

A human player enters moves one round at a time:
- `R` → Rock  
- `P` → Paper  
- `S` → Scissors  

Your program must:
1. Track user behavior across rounds.
2. Predict the user’s next move.
3. Select the counter-move that would beat them.
4. Update the model after each round.

This challenge tests your ability to:
- Process sequential game data  
- Implement a pattern-learning algorithm  
- Build a dynamic prediction system
